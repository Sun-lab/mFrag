# Data availability (manuscript back matter)

**Data availability.** LUCAS cohort shallow whole-genome sequencing cfDNA data and associated clinical metadata are available under controlled access through the European Genome-Phenome Archive (EGA) study accession **EGAS00001005340** (Mathios *et al.*, *Nat. Commun.* 12, 5060; 2021). Access requests should be submitted to the LUCAS study data access committee and approved under the applicable data-use agreement. Processed fragmentomic feature matrices (589×24 z-scored per-sample tables), mFrag-Weight row-zscored wide feature tables, per-sample model predictions, and bootstrap performance summaries generated in this study are publicly available at **https://github.com/Sun-lab/mFrag** under `data/` (see `data/README.md` for file manifest). Key paths: `data/lung_cancer/` (mFrag-Net inputs), `data/mfrag_weight/` (mFrag-Weight inputs), `data/predictions/`, and `data/bootstrap/`. Source Data accompanying this paper reproduce the primary figure statistics.

External whole-genome bisulfite sequencing (WGBS) reference methylation profiles were obtained from publicly available resources: healthy cfDNA and cell-type WGBS from Loyfer *et al.*¹⁰ (*Nature* 613, 355–364; 2023; GEO: **GSE186458**; raw reads additionally at EGA **EGAS00001006791** upon approved access), and primary lung tumor WGBS from Zhang *et al.*¹¹ (*Cell Rep.* 44, 116197; 2025; GEO: **GSE212391**).
