## Supplementary File 1

One row per 5-Mb autosomal window (589 total). Generated by:

```bash
python code/scripts/build_supplementary_file_1.py
```

| Column | Description |
|--------|-------------|
| `sl_ratio_coupling_weight` | \|Δβ\| / mean(\|Δβ\|) for mFrag-Weight (S/L) |
| `mds_coupling_weight` | max(1 − λ·Δβ̃, 0.05), λ=0.5 for mFrag-Weight (MDS) |

## GitHub release note

Per-sample feature matrices are large (~700+ CSV files). In public GitHub releases, either:

1. Host matrices on Zenodo/Synapse and document download URLs here, or
2. Ship preprocessing scripts only and let users rebuild from BAMs.

Development checkouts use symlinks to `../Mathios/Final_data_24/`.
